# خطوات رفع التحديثات (Frontend فقط)

## ما الذي تحتاج رفعه؟

التعديلات كانت في **الواجهة الأمامية (Frontend)** فقط، لذلك:

- **لا تحتاج** رفع أي شيء للـ Backend (api.letspeak.online).
- **تحتاج** فقط إنشاء نسخة **build** جديدة ورفعها إلى السيرفر الذي يخدم **sys.letspeak.online**.

---

## الخطوات

### 1) على جهازك (بعد دفع التغييرات لـ Git)

```bash
cd frontend
npm install
npm run build
```

سيُنشأ مجلد **`dist`** ويحتوي على الملفات الجاهزة للإنتاج (HTML, JS, CSS مُجمّعة ومُصغّرة).

### 2) رفع الملفات للسيرفر

ارفع **محتويات مجلد `dist`** إلى المسار الذي يخدم منه الموقع **https://sys.letspeak.online** على السيرفر.

- إن كان السيرفر يعرض الموقع من مجلد معيّن (مثل `/var/www/sys.letspeak.online` أو `/var/www/html`)، انسخ محتويات `dist` فوق محتويات ذلك المجلد (استبدال الملفات القديمة).
- يمكنك استخدام:
  - **SCP**: `scp -r dist/* user@server:/path/to/sys.letspeak.online/`
  - **SFTP** (FileZilla أو غيره): ارفع كل ما داخل `dist` إلى مجلد الجذر الخاص بالموقع.
  - أو إن كان لديك وصول SSH: انسخ المشروع على السيرفر، نفّذ `git pull` ثم `npm run build` داخل `frontend`، ثم انسخ محتويات `dist` إلى مجلد الموقع.

### 3) التحقق

افتح **https://sys.letspeak.online** وتأكد أن جدول المحاضرات يظهر بالتنسيق الجديد (توسيط الأعمدة وعرض عمود دفع المدرب).

---

## ملخص

| المكوّن        | هل تحتاج رفعه؟ | ماذا ترفع؟                          |
|----------------|----------------|-------------------------------------|
| Backend (API)  | لا             | —                                   |
| Frontend (sys) | نعم            | **محتويات مجلد `dist` فقط** (نسخة الـ build) |

لا تحتاج رفع مجلد `src` أو `node_modules` أو أي ملفات مصدرية — فقط **الـ build** (مخرجات `dist`).
